# 表情包代替说话 (emoji-sticker)

AstrBot 插件:监听 LLM 的回复,在合适的场景(撒娇、晚安、开心、生气、安慰、庆祝)下,调用 **OpenAI 兼容的图片生成 API** 生成表情包图片,用图代替/点缀文字,让聊天更有温度。

> 不每条都发!由概率 + 冷却 + 每日限额 + 同场景去重 共同控制,大部分消息仍是正常文字。

---

## 功能特性

- **LLM 主动选择**:注册了 `send_sticker` 工具,LLM 可以自己判断当前场景是否适合发表情包。
- **关键词自动触发**:监听回复文本,命中场景关键词后按概率触发(20%~40%),在文字后追加一张图。
- **显式标记**:LLM 可在回复中输出 `[STICKER:撒娇]` 强制发一张该场景的表情包(受额度限制)。
- **异步不阻塞**:图片生成在后台进行,不影响正常 LLM 回复速度。
- **OpenAI 中转站兼容**:只需配置 `base_url` 和 `api_key`,支持 `gpt-image-1`、`gpt-image-2`、`dall-e-3`、`qwen-image`、`cogview-3` 等任何兼容 `/v1/images/generations` 的模型。

## 防过度触发机制

| 机制 | 默认值 | 说明 |
| ---- | ---- | ---- |
| 概率触发 | 30% | 命中关键词后真正发图的概率(可配 20%~40%) |
| 冷却时间 | 7 条消息 | 两次发图之间至少间隔的消息数 |
| 每日限额 | 3 次/场景 | 每种表情包类型一天最多发几次 |
| 同场景去重 | 每天 1 次 | 同一天同一种表情最多发一次 |

所有状态保存在内存中,重启 AstrBot 后清零。

## 安装

1. 将本文件夹 `astrbot_plugin_emoji_sticker` 复制到 AstrBot 的 `data/plugins/` 目录下
2. 在管理面板「插件」中启用插件
3. 填写配置:
   - `API 基础地址`:中转站地址,如 `https://api.openai.com/v1` 或 `https://your-relay.com/v1`
   - `API Key`:你的密钥
   - `图片生成模型`:如 `gpt-image-1`、`qwen-image`
   - 其余参数按需调整

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| ---- | ---- | ---- | ---- |
| `base_url` | 文本 | `https://api.openai.com/v1` | 兼容 OpenAI 的 API 地址 |
| `api_key` | 文本 | 空 | API 密钥 |
| `model` | 文本 | `gpt-image-1` | 图片生成模型 |
| `image_size` | 文本 | `1024x1024` | 图片尺寸 |
| `trigger_probability` | 滑条 | `0.3` | 关键词触发概率 |
| `cooldown_messages` | 数字 | `7` | 冷却消息数 |
| `daily_limit` | 数字 | `3` | 每场景每日上限 |
| `timeout` | 数字 | `60` | 生成超时(秒) |
| `send_mode` | 下拉 | `append` | `append`=文字+图片;`replace`=仅发图片 |
| `scenes_json` | 文本 | 空 | 自定义场景(JSON) |

## 自定义场景关键词

在 `scenes_json` 中填写 JSON,格式如下。未填写的部分使用默认场景;填了会覆盖同名场景、新增新场景。

```json
{
  "撒娇": {
    "keywords": ["撒娇", "想你", "亲亲", "贴贴", "mua"],
    "prompt": "可爱的二次元卡通少女撒娇表情包, 嘟嘴, 比心, 害羞, 红色腮红, 透明背景, 高清",
    "weight": 1.0
  },
  "饿": {
    "keywords": ["饿了", "好饿", "想吃", "干饭"],
    "prompt": "二次元卡通人物流口水想吃表情包, 捂着肚子, 眼里冒星星, 透明背景, 高清",
    "weight": 0.8
  }
}
```

- `keywords`:触发关键词列表(包含即命中)
- `prompt`:生成图片的提示词模板
- `weight`:触发权重(0.1~1.0),权重越高越容易触发

支持简写形式:`{"撒娇": ["想你", "亲亲"]}`。

## LLM 工具调用

插件注册了工具 `send_sticker(scene: str)`,LLM 可主动调用。当 LLM 判断当前场景适合发图时,它会直接调用工具而不用等待关键词命中。

```text
用户: 我有点难过...
Bot: [调用 send_sticker("安慰")] 别难过啦,抱抱~
```

`send_mode = append` 时:文字和图片都会发送。
`send_mode = replace` 时:仅发送图片,并提示 LLM 不要输出重复文字。

## 显式标记

LLM(或你通过 prompt 引导 LLM)可在回复文本中包含 `[STICKER:场景]`,插件会为该场景生成表情包:

```text
Bot: 晚安啦~ [STICKER:晚安]
```

标记会从文字中移除(仅发图时),该次触发不受概率限制,但仍受冷却和每日配额限制。

## 注意事项

- 图片生成依赖中转站/API 提供商,生成耗时约 1~10 秒,插件在后台等待,不影响 LLM 回复速度。
- 部分模型(如 `dall-e-3`)不支持 `response_format=b64_json`,插件会自动回退到 URL 下载方式。
- 所有限制状态(冷却、每日计数)保存在内存,重启后重置。
- 请确保你的 API 账户有图片生成额度,否则会打印错误日志并退回纯文字回复。
